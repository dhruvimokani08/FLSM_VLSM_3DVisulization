1. Project Overview

This project compares Fixed Length Subnet Masking (FLSM) and Variable Length Subnet Masking (VLSM) for five departments requiring 70, 35, 18, 9 and 5 host addresses.

Objective: Compare address allocation, usable host capacity and address utilisation while validating subnet boundaries and preventing overlaps.

7. Conclusion

FLSM allocates 640 addresses, while VLSM allocates 248 addresses for the same five department requirements. VLSM saves 392 addresses, a reduction of 61.25% in allocated address space. This demonstrates more efficient address allocation with VLSM. These calculations alone do not establish that VLSM has better network performance.
